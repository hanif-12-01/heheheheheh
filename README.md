## 🎮 Overview

**HANIF.EXE** is an interactive, modern portfolio that blends high-credibility software engineering with nostalgic 16-bit indie-RPG aesthetics. 

### Key Features
- **Spawn Point (Hero Section)**: Dynamic introductory stage with interactive avatar frame and direct navigation anchors.
- **Pixel Hanif Companion Pet**: Reactive pixel character companion with multiple state poses (`idle`, `wave`, `coding`, `walk`, `reading`, `trophy`, `rocket`, `sleep`) and easter-egg dialogue bubbles.
- **Dual Mode System**: Toggle seamlessly between **Pixel Mode** (retro RPG visual language with CRT scanlines & companion) and **Recruiter Mode** (clean corporate/developer typography and distraction-free view).
- **Normalized World Assets**: Pixel-art production assets across semester milestones, achievement badges, and technical domain illustrations.
- **Responsive Architecture**: Fully responsive across mobile (down to 320px), tablet, and desktop viewports with reduced-motion accessibility support.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) 16 (App Router, Turbopack)
- **Library**: [React](https://react.dev/) 19
- **Language**: [TypeScript](https://www.typescriptlang.org/) (Strict mode)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) v4 & Custom Pixel Design Utilities
- **Icons**: Lucide Icons & Custom Pixel UI Icons
- **Animation**: CSS animations with `prefers-reduced-motion` compliance

## 🚀 Getting Started

### Prerequisites
- Node.js 18.18+ or 20+
- npm, yarn, or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/hanif-12-01/heheheheheh.git
   cd heheheheheh
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Build & Production

To create an optimized production build:

```bash
npm run build
npm run start
```

To run lint checks:

```bash
npm run lint
```
